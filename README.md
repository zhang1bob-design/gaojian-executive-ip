# 高见｜EXECUTIVE VOICE

> 高见，值得被看见。

《高见》是一个面向公关与品牌团队的高管 IP 公众号选题生成器。它把高管履历、行业观点、业务目标和目标受众，转化为一句话定位、三个记忆标签、三个长期内容方向及三天公众号选题。

## 在线功能

- 手机优先的六页数字商业杂志体验
- 右滑翻页与键盘方向键导航
- 两步结构化高管资料录入
- 浏览器端策略生成，不上传用户填写的信息
- 生成一句话 IP 定位、三个标签与三个长期内容方向
- 生成三个公众号选题，每个包含角度、Hook 和三点大纲
- 结果支持直接编辑、复制和单页重新生成

## 项目定位

这是使用 Codex 完成开发的交互式策略产品原型。当前版本采用浏览器端结构化策略引擎，不调用外部大模型 API，因此可以直接部署到 GitHub Pages，运行时零调用费用。

## 本地运行

使用任意静态服务器打开项目根目录。例如：

```bash
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 隐私

当前版本不提供账号、数据库或历史记录，填写内容只在当前浏览器页面中处理，刷新后清空。

## 视觉资产

封面使用原创 AI 生成的虚构人物，不对应任何现实人物；酒红、墨黑与新闻纸米白构成克制的财经杂志视觉，版式与报纸翻页交互均为本项目定制。
